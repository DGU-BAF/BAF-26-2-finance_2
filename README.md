# 금리 상승기, 어떤 제조업 업종의 이자상환능력이 더 흔들렸나

> 2026-2학기 B.A.F 프로젝트 중간발표용 레포지토리 (2026-10-01 기준). 모든 결과는 **예비 단계**이며 최종 결론이 아니다.

## 1. 한 줄 소개
한국은행이 기준금리를 올리기 시작한 2021년 8월 **이전**에 단기 차입 비중이 높았던 제조업 업종일수록, 인상 **이후** 이자보상비율(ICR)이 더 크게 나빠졌는지 확인한다.

처음 보는 사람을 위한 용어
| 용어 | 뜻 |
|---|---|
| 이자보상비율(ICR) | 영업이익 ÷ 이자비용. 값이 클수록 이자를 갚을 여력이 크다 (100% = 영업이익이 이자와 같음) |
| 단기부채 노출도 | (단기차입금 + 단기사채) ÷ 총자산의 인상 이전 평균. 금리가 오르면 빨리 다시 빌려야 하는 빚의 비중 |
| 유동비율 | 유동자산 ÷ 유동부채. 단기 지급 여력의 대리 지표 (현금 보유량 자체는 아님) |
| 긴축기 / 비교기간 | 긴축기: 사전 2018~2020, 전환 2021, 인상 이후 2022~2023. 비교기간: 사전 2015~2017, 가상의 사후 2018~2019 (이 기간에도 금리 변동이 있어 충격이 없는 시기가 아니다) |

## 2. 분석 개요
- 대상: ISTANS 제조업 40개 업종 × 연도 (긴축기 240관측, 비교기간 200관측)
- 모형(예비): `ICR_it = β·(Post_t × 사전노출도_i) + 업종 고정효과 + 연도 고정효과`, 표준오차는 업종 군집
- 통제 후보: 원자재 가격 충격(산업연관표 기반), 반도체 사이클, 환율 노출(포함 여부 EDA 후 결정)
- 예비 결과: β ≈ +53.7 (노출도가 높을수록 ICR이 더 악화될 것이라는 가설과 **반대 방향**), 통계적으로 유의하지 않음(p ≈ 0.19). 반도체 업종을 빼면 28.2로 줄고, 사전추세 신호가 일부 있어 인과 해석은 어렵다.
- 모형·기간·통제·ICR 변환 등 주요 결정(D1~D7)은 진행 중이다 → `docs/decisions/결정로그_및_남은작업.md`

## 5. 실행 방법
```bash
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python scripts/run_all.py            # 스크립트 + 노트북 전체 (시간이 걸림)
python scripts/run_all.py --scripts  # 원자재 충격지표 스크립트만
```
- 모든 경로는 레포 루트를 자동으로 찾는 **상대경로**다. 노트북 첫 셀("경로 설정")이 `data/` 폴더를 찾아 `RAW / INTERIM / PROCESSED`를 정한다. 폴더 구조를 바꾸지 말 것.
- 권장 순서: `src/02_rawmaterial_shock` 01→05 → `src/03_panel` 01→02 → `src/04_eda` 1→13.
- **`src/01_data_check` 두 노트북 주의**: 엑셀 저장에 쓰는 `artifact_tool`은 일반 환경에 없는 모듈이다. 없으면 엑셀 저장 단계를 건너뛴다(결과는 `data/interim/ISTANS_7단계_예비추정_결과.xlsx`, `outputs/tables/결측지도.xlsx`에 포함). 이후 단계는 이 결과 파일을 읽으므로 그대로 실행된다.
- `data/interim/기준금리_연도별.csv`의 2026년 행은 부분 연도라 노트북 7번을 실행하는 날짜에 따라 연평균 값이 조금 달라진다(분석에는 쓰지 않음).
- ISTANS 원자료 파일명은 내려받은 시각이 붙어 있다. 코드와 이름이 연결되어 있으니 바꾸지 말 것.

## 8. 한계 (현재 알고 있는 것)
- 단일 긴축 사건과 동시에 일어난 충격(원자재, 반도체, 환율)을 분리하기 어렵다.
- 업종 군집이 40개뿐이라 소표본 추론 문제가 있고, 최소 검출 가능 효과(약 113)가 커서 검정력이 낮다.
- 추정치가 반도체·통신기기 업종에 민감하다. 좁은 사전기간 창에서는 사전추세 신호(p=0.033)가 있다.
- 노출도를 "단기 빚 비중"으로 두는 것은 설계 가정이며 검증된 사실이 아니다.
- 업종 단위 집계 자료라 기업 간 차이를 볼 수 없고, 결과는 인과효과가 아닌 조건부 연관성으로 해석한다.
