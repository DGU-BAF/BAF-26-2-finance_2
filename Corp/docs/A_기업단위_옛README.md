# A(기업 단위) 파일럿 — 사용 방법

## 이 폴더에 있는 것

| 파일 | 내용 |
|---|---|
| `A_사전고정_문서_초안.md` | 분석을 돌리기 전에 정할 것(표본·변수·모형·보고 규칙·파일럿 기준). **먼저 읽고 팀이 [미정] 항목을 채운다** |
| `pilot/config.py` | 설정(연도, 보고서 코드, 표본 수, 시드, 제조업 업종코드 접두어) |

| `pilot/01_corp_list.py` | 상장사 목록 + 표본의 기업개황 → 업종코드 체계 확인 |
| `pilot/02_pilot_fetch.py` | 파일럿 기업 추출(층화 무작위) + 재무제표 수집 |
| `pilot/03_check_pilot.py` | 확보율·계정명 변형·분기 환원 항등성·단위 점검 |

- 스크립트는 **파이썬 표준 라이브러리만** 씁니다(별도 설치 불필요).
- **회귀·계수·유의성은 어디서도 계산하지 않습니다.** 파일럿은 "자료를 뽑을 수 있는가"만 봅니다.

## 인증키 설정 (중요)

1. OpenDART(opendart.fss.or.kr)에서 본인 계정으로 인증키를 신청합니다. 가입과 신청은 직접 하셔야 합니다.
2. **키를 파일에 쓰거나 채팅에 붙여넣지 마세요.** PowerShell 창에서 아래처럼 환경변수로만 설정합니다. 그 창을 닫으면 사라집니다.

```powershell
$env:DART_API_KEY = "여기에 발급받은 40자리 키"
```

스크립트는 키를 출력하거나 저장하지 않습니다(오류 메시지에도 주소를 넣지 않음).

## 실행 순서

```powershell
cd "…\논문경진대회\분석 방향\A_기업단위\pilot"
```

**0) 모집단 점검 (인증키 불필요, 아직 하지 않음)**

- 한국거래소 KIND의 상장법인 목록과 상장폐지 현황을 읽어서 시장별·제조업 기업 수를 세고, DART 목록(`out/listed_all.csv`)과 기업 수를 대조합니다.
- 사전기간(2019–2021)에 상장했다가 이후 폐지된 기업이 DART 목록에 있는지, 재무자료가 남아 있는지 확인합니다.
- 이 단계는 **스크립트가 없습니다.** 조회는 공개 자료 읽기이며 사용자 허락을 받은 뒤 진행합니다(사전 고정 문서 9절 0단계, A9·A14).

**1) 업종코드 체계 확인**

```powershell
python -X utf8 01_corp_list.py
```

- 상장사 목록을 받고, 무작위 150개 기업의 기업개황을 받습니다(호출 약 150건).
- `out/company_probe.csv`를 열어 `induty_code`가 어떤 체계인지 **값으로** 확인합니다. (가이드에 설명이 없습니다.) 이름이 알려진 제조기업의 코드와 서비스업 기업의 코드를 비교하면 규칙을 알 수 있습니다.
- 확인한 뒤 `config.py`의 `MANUFACTURING_PREFIXES`를 채웁니다. **비어 있으면 02가 실행을 거부합니다.**

**2) 파일럿 기업 뽑기 + 수집**

```powershell
python -X utf8 02_pilot_fetch.py --dry-run
python -X utf8 02_pilot_fetch.py
```

- `--dry-run`은 호출 수만 계산합니다. 기본 40개 × 7년 × 4보고서 = 최대 1,120건(연결에 자료가 없으면 별도를 다시 부르므로 최대 2배).
- 받은 응답은 `raw/fs/`에 그대로 저장되고, **다시 실행하면 이미 받은 파일은 건너뜁니다.** 요청 제한(상태 020)이 나오면 멈추고, 내일 같은 명령으로 이어서 합니다.
- 표본은 법인구분·업종코드 앞 2자리별로 돌아가며 뽑습니다. 이름 기준 지주/스팩은 **표시만** 하고 자동 삭제하지 않습니다.

**3) 점검**

```powershell
python -X utf8 03_check_pilot.py
```

`out/`에 결과가 저장됩니다.

| 파일 | 볼 것 |
|---|---|
| `pilot_account_coverage.csv` | 대상 계정이 얼마나 구해지는가 |
| `pilot_account_variants.csv` | 계정명 변형 목록. **이걸 보고 `03_check_pilot.py`의 `TARGETS` 정규식을 고친다** |
| `pilot_quarterly_check.csv` | Q1+Q2=반기누적, 반기누적+Q3=3분기누적 항등성, Q4(=연간−3분기누적) |
| `fetch_log.csv` | 호출별 상태 |

## 점검 후 판단

- 통과 기준은 **결과(유의성)가 아니라 추출 가능성**으로만 정합니다(사전 고정 문서 9절).
- 실패가 "계정명 변형처럼 규칙으로 고칠 수 있는 것"인지 "구조적으로 구할 수 없는 것"인지를 가르는 게 핵심입니다.
- 이자비용 확보 방법이 정해지지 않으면 A는 진행하기 어렵습니다(손익계산서 이자비용 / 금융비용 / 현금흐름표 이자지급 / 주석).

## 파일럿에서 꼭 같이 볼 것 (스크립트가 자동으로 못 보는 것)

- **상장폐지 기업이 목록에 있는가:** 사전기간(2019–2021)에 상장돼 있다가 이후 폐지된 기업 몇 곳을 이름으로 찾아 `out/listed_all.csv`에 있는지 확인하세요. 없다면 기업 목록 자체에 생존편향이 있는 것입니다(사전 고정 문서 3절).
- **계정이 "없는" 것과 "못 구한" 것의 구분:** 유동성사채처럼 해당 기업에 원래 없는 항목은 응답에 안 나옵니다. `pilot_account_coverage.csv`의 낮은 확보율을 곧바로 추출 실패로 읽으면 안 됩니다(사전 고정 문서 5절).
- **회계기준 변경:** K-IFRS 제1116호(리스)가 2019-01-01에 시행되어 이자비용·부채 범위가 바뀌었습니다. 후행 4분기 합산이 2019Q1–Q3에서 변경 전후를 걸칩니다(사전 고정 문서 A11).
- **코로나19 금융지원:** 중소기업·소상공인 대출 만기연장·상환유예가 2020-04부터 반복 연장됐습니다. 단기차입의 재차환 위험 해석에 영향을 줄 수 있습니다(A12, 뉴스 수준 확인).
- **정정공시:** API 값이 원보고서 값인지 정정 후 값인지 가이드에 설명이 없습니다. 파일럿에서 접수번호를 비교하세요(A13).
- **기업별 표** `pilot_firm_coverage.csv`로 실패가 몇몇 기업에 몰렸는지, 전반적인지 확인하세요(사전 고정 문서 9절 판정 방식).

## 알려진 한계 (이 스크립트가 아직 안 하는 것)

- 일괄 다운로드(TXT/TSV) 파일은 다루지 않습니다. 가이드에서 파일 목록·연도 범위·컬럼 정의를 확인하지 못했습니다. 호출 제한이 문제가 되면 그때 검토합니다.
- 주석(XBRL) 파싱은 하지 않습니다.
- 계정명 매핑(`TARGETS`)은 첫 추정입니다. 파일럿 결과를 보고 고칩니다.
- (2026-11-03 갱신) 01~03은 실제 OpenDART 응답으로 실행했습니다(파일럿 28곳, 전체 상장사 기업개황 4,009곳). 04 예시표는 19곳 시점이라 낡았고, 선별·수집 스크립트는 아직 없습니다. 현재 상태와 다음 할 일은 `인수인계_메모.md`를 보세요.
