한 줄 요약

상장 제조기업 1,321곳(선별·A2 적용 후)의 분기 재무자료를 받아, 업종 분석에서 한 틀(M1~M3, 사전추세, 극단값, 반도체·업종 제외, 실제금리 대안, 구성요소)을 기업 단위로 옮겨 본다. 업종 분석은 업종 사이를, A는 같은 업종 안을 비교한다.

2. 업종 분석(v1)에서 가져온 것 · 새로 찾은 문제

v1 검토 결과

  • 이미 사양이 많다(팀 문서 65개 작업) 팀 문서. 더 얹으면 다중비교만 늘므로, 11/12 전에는 추가보다 정리가 낫다고 본다 제안.
  • 정의 확인이 가장 큰 구멍: ISTANS 차입 4항목 범위·ICR 산식·집계 모집단이 미확인 팀 문서. A는 DART 계정으로 정의가 투명해서 이를 보완할 수 있다 제안.
  • v1의 주 결과(M2 E×Post 0.5459, p=.2343, 업종 40개)는 직접 맞춰 봤고 팀 문서와 일치 확인. 노트북 코드는 재실행·검증하지 않았다.

회귀 전에 정해야 할 새 문제 (제가 찾은 것)

B-1. 긴축 변수가 사전기간에도 움직인다 확인

Tight = 분기말 기준금리 − 2021Q2 금리(0.50%). rates.csv 기준 2019Q1 +1.25, 2019Q4 +0.75, 2020Q1 +0.25, 2020Q2~2021Q2 0, 2022 이후 증가. 인하기(2019~2020)에 이미 양수라서 하나의 β가 인하와 인상을 한 직선에 묶는다.

제안 기본값주 사양은 v1과 같은 Post 더미(2022 이후, 2021은 전환항). 이유: v1과 직접 비교되고 인하기가 섞이지 않는다. 연속형 금리(인상분만 max(0, 금리−0.50))는 보조, 이벤트스터디(분기별 계수)는 필수.

B-2. 연결/별도가 섞인 기업 63곳 확인

2019 사업보고서와 2021 반기보고서의 구분이 다르다(연결→별도 21, 별도→연결 43, 통과 전체 기준 64곳 중 A2 적용 후 63곳). 원인은 확인하지 못했다(연결 작성 의무 시작 등은 가설).

제안 기본값수집은 보고서별로 그대로 받아 두고, 주 분석은 혼재 기업 제외, 강건성에서 포함. 제외된 63곳이 업종·규모·E에서 쏠리는지 A8 점검 목록에 추가.

B-3~B-6
  • B-3 수집 범위: 문서대로 2018~2024Q3(약 33,000건). 2018을 빼면 약 5,300건 감소하지만 리스 기준(A11) 선택지가 줄어든다. 제안 포함.
  • B-4 별도(OFS) 기업: 매 보고서마다 연결을 먼저 조회하면 요청이 약 2배. 선별 결과의 구분을 기억하게 설계. 단 연결로 바뀌는 기업이 있어 예외 처리 필요.
  • B-5 업종 셀 크기: 5곳 미만 12번(1곳)·16번(4곳)·18번(2곳), 10곳 미만 12·15·16·18·19·32번 확인. A5 기준 필요.
  • B-6 지주회사 21곳: 이름 기반 표시이므로 수동 검토.
