# 추가분석 v2 재현
보고서: 전체분석_통합보고서_v2.html (더블클릭하여 브라우저에서 열기)
07_development.ipynb: 추가 분석 코드와 저장 출력. 원자료·기존 분석은 수정하지 않았음.

Python 3.12, requirements.txt 설치 후 이 폴더를 작업경로로 노트북의 모든 셀을 순서대로 실행한다. inputs/panel.csv는 mechanism_v1의 동결 패널이며 원천 재무자료 구축은 01,05 노트북 참조. inputs/manifest.json에 출처와 SHA256이 있다. 별도의 절대 입력 경로 수정은 필요 없다.
실제 검증은 동일 Python 네임스페이스에서 3개 코드 셀을 순차 실행한 방식이다. Jupyter 새 커널 전체실행 검증은 하지 않았다. 모든 코드 출력 및 execution_count를 보존했다.
N1/N2 대비의 점추정·군집 표준오차를 동등 재매개화로 대조했고, 부트스트랩 전에 업종효과 제거 후 계수 동일성과 행렬 계수를 확인했다. 군집 40개, CR1+t39, bootstrap 9999회 seed20261103. 모든 8개 핵심검정을 공개했으며 Holm은 이 8개 묶음 내 보정이다.
요구 자료와 미실행 사항은 보고서 5절. 개별 HTML을 공유해도 표는 모두 포함된다. CSV·노트북 링크를 함께 사용하려면 전체 ZIP을 압축 해제한다.
