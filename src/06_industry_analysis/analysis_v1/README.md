# 실행 결과 v1

먼저 `검토와_분석결과.html`을 여세요. 팀 공유용 검토·결과·문헌 근거·필요 자료가 있습니다.

`01_analysis.ipynb`는 10개 코드 셀을 순서대로 실제 실행하고 출력을 저장한 노트북입니다. 입력은 inputs의 원본 복사본입니다. 원본 프로젝트는 수정하지 않았습니다.

재실행: Python 3.12 환경에 `pip install -r requirements.txt`로 의존성을 설치하고, Jupyter/VS Code에서 노트북 폴더를 작업 폴더로 선택해 전체 실행하세요. tables/figures 결과는 재생성됩니다. Windows에서는 Malgun Gothic을 사용했고 다른 OS에서는 폰트 지정이 필요할 수 있습니다.

본 분석은 조건부 관계 추정입니다. 공식 재무항목 구성 및 ICR 집계 정의는 추가 확인 대상입니다. 학술 인과효과 또는 논문 완성이 아닙니다.
