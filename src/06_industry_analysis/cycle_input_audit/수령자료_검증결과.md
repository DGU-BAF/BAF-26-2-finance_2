# 생산·출하 자료 수령 검증

- 기간: 2017–2023년 연간. 생산·출하 원지수, 2020=100, 코드 포함 확인.
- 43행 = 세부 38업종 + 제조업 합계 1개 + 기술산업군 4개. 기존 40개와 일치하는 코드는 38개이며 이름도 일치.
- 기타 전자부품(I3203), 세라믹(I3305): 파일에 행 없음. 사용자의 선택 누락인지 원 통계 미제공인지 파일만으로 확정 불가.
- 기타 수송장비(I3209): 2017–2019 생산·출하 값 모두 '-'(6셀). 실제 0으로 바꾸지 않음.
- 100×ln(당년지수/전년지수) 계산 시 기타 수송장비의 2018–2020 변화는 계산 불가. 2021–2023은 가능.
- 현재 기존 240 업종-연도 중 225행에 두 증가율이 모두 존재. 이대로 완전관측만 쓰면 38업종225행 비균형 표본이 됨. 37개 완전업종만 쓰면222행이며, 어느 쪽도 이번에 승인·실행하지 않음.
- 메타자료는 통계표ID·출처·URL·원출처만 제공. 분류 개정/연간 집계 방법 설명은 없음. 금액자료의 모집단과 동일하다고 입증한 것도 아님.

## 필요한 보완
1. 동일 통계표에서 기타 전자부품·세라믹 선택 여부 확인 후, 가능하면 두 업종의2017–2023 원지수 추가 다운로드.
2. 기타 수송장비의2017–2019가 사이트에도 '-'인지 확인. 미제공이면 채워 넣지 말고 표본 변경을 별도 결정.
3. 보완이 불가능한 경우 제안: 기존40업종 주 분석 유지, 경기통제 비교만 같은 완전관측 표본에서 통제 전/후 나란히 추정. 이는 미승인 제안이며 아직 회귀하지 않음.
