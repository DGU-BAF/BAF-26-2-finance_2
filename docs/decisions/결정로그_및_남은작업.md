## 외부 검토 반영 (2026-10-01, 에이전트 재검토 포함) — 추가·수정 항목
**목록에 추가**
- 완충효과 모형: `Post×노출도×현금여력`(+하위 항)으로 "현금여력이 노출도 효과를 바꾸는가"를 직접 검정(검토보고서 다음 할 일 03번에 "필요하면 3중상호작용"으로 있었으나 이 목록에서 빠졌음). 현재 모형은 두 항을 따로 넣을 뿐 완충을 검정하지 않음. 표본이 작아 보조 질문으로 둘지 결정 필요.
- 2021년 전환연도 보조모형: `2021 더미×사전노출도`(현금여력 포함 시 해당 항도).
- 노출도 계산 사전기간과 ICR 비교 사전기간은 별개 선택 → 코로나 점검 시 둘을 동시에 바꾸지 않기.
- 용어: 유동자산/유동부채는 정확히는 **유동비율**(현금 보유량과 다름). 문서·발표의 "현금여력" 표현 정리 여부 결정.
- 긴축기 vs 평시 계수 차이 검정 시 두 분석이 같은 업종·일부 연도를 공유한다는 점 반영.
- 대체 종속변수(D6) 우선순위 상향: ICR 분자가 음수이면 이자부담이 커져도 ICR이 오를 수 있음(우리 자료 ICR<0은 16/240, 6.7%). 후보: 영업이익률, 이자비용/사전기간 평균자산, 가능하면 이자비용/평균 이자부채. 주 결과와 보조 결과를 사전에 구분(다중 결과 문제).
- 단기·장기 차입/자산 동시 모형(D5)에서 두 계수의 **차이를 직접 검정**.

**수정·정정**
- Post 정의 A~D는 같은 질문의 대안이 아님(B만 표본 민감도, C·D는 비교 구조가 바뀜). D의 p=0.042를 근거로 삼지 않음.
- 반도체 그룹 정의: 투입산출표 "반도체 투입 비중"은 반도체 구매 업종의 노출도라 목적에 맞지 않을 수 있음 → 반도체 제조업을 공식 코드로 먼저 정의.
- 통제변수 선택은 통계적 관련성뿐 아니라 인과 구조(경로 변수 여부)로 판단.
- 광공업생산지수(업종별)·인건비는 금리 이후 조정의 결과일 수 있어 기본 통제로 자동 투입하지 않음.
- wild bootstrap: boottest 원문은 Queen's QED 워킹페이퍼 1406(Roodman·MacKinnon·Nielsen·Webb, 2018, 이후 Stata Journal 19(1))으로 존재 확인(이 세션에서 PDF 본문은 서버 인증서 오류로 열지 못했고 검색으로 존재만 확인).

## D1 결정 기록: ICR 변환 → (가) 원자료를 주 결과로 (2026-10-01)

**결정**: 사용자(팀)가 (가) 원자료 ICR을 주 결과로 정함. 팀원 한 명의 서면 의견도 (가)를 권고했고, 그 의견의 사실 주장은 아래 "팀 의견 검토"에서 직접 대조했다. 이 절의 근거 중 "에이전트 제안"과 "직접 확인"은 구분해 적었다.

### 1. 다른 방법과 우리 자료에 적용하면

**먼저 알아둘 점**: 확인한 문헌 대부분이 "0이 많은 0 이상 변수"(특허 수, 소득 등)를 다룬다. 우리 ICR은 0 덩어리가 없고 음수가 있는 변수라서, "선행연구가 이렇게 한다"를 직접 근거로 삼을 사례가 없었다. 또 Chen·Roth(2024)가 보인 "단위를 바꾸면 효과 크기가 임의로 달라진다"는 결과는 0에서 양수로 바뀌는 관측이 있을 때의 결과이며, 이 논문은 음수 outcome을 각주 5에서 명시적으로 제외한다. 따라서 asinh의 단위 의존성은 우리 자료에서 "있을 수 있는 문제"이지 이 논문이 증명한 문제가 아니다(이전에 "문헌에서도 지적됨"이라고 쓴 표현을 이렇게 정정).

| 단점 | 극단값·이분산에 민감 | 1%는 관행이며 경계가 표본 전체 값으로 정해짐 | 나누는 상수(1·100·1000)에 따라 결과가 달라짐(단위 의존성) |
| 우리 자료에서의 문제 | 소수 관측이 결과를 좌우할 가능성(실제로는 아래 근거 3에서 작게 측정됨) | 잘리는 6개 중 3개가 담배 2020~2022 → 담배의 ICR 상승(8,644→12,961→13,480)이 8,288로 평평해짐 | 상수 선택이 곧 사양 선택. 음수 반전은 해결 못 함 |
| 판단 | **채택(주 결과)** | 강건성으로 보고 | 강건성으로 보고(%효과로 읽지 않는다고 표기) |

**그 밖의 방법**

| 방법 | 우리 자료에서의 문제 | 판단 |
|---|---|---|
| **로그** | ICR>0만 가능하다. 16/240행이 음수라 빼면 적자 업종-연도를 제거하는 표본 선택이 된다 | 비추천 |
| **log(상수+ICR)** | 최솟값이 -963이라 큰 상수가 필요하고, 상수가 임의다 | 비추천 |
| **차분(ΔICR)** | 업종 고정효과가 이미 업종별 수준 차이를 없앤다. 차분이 유리한 경우는 오차가 해마다 강하게 이어질 때인데 우리 잔차 자기상관은 0.10이다(10번 6-5). 극단값이 한 해 튀면 차분에서는 전년·당해로 두 번 나타나고, 왜도도 줄지 않는다. (차분의 일반 이론은 이번 세션에서 문헌 본문 미확인) | 이득이 작음 |
| **긴 차분**(사전평균 vs 사후평균, 업종당 1행) | 관측이 40개로 줄고 사실상 2×2 모형(10번 6-9, +69.1)이다 | 참고용 |
| **변화율(%Δ)** | 분모가 0 근처이거나 음수이면 정의가 망가진다 | 비추천 |
| **순위 변환, 중앙값(LAD)·분위 회귀, 로버스트 회귀(Huber 등)** | 극단값 영향이 줄고 고정효과와 결합할 수 있는 방법이 있다. 대신 해석이 "중앙값 효과" 등으로 바뀌고 군집 SE·wild bootstrap과 연결하는 작업이 추가된다 | 강건성 후보(R4) |
| **Poisson(PPML)** | 0 이상이어야 해서 음수 ICR에 쓸 수 없다 | 불가 |
| **ICR<1 기업 비중**(임계값 방식) | 기업 단위 자료가 필요하다. 현재 자료는 업종 집계라 불가능해 보인다(확인 필요) | 어려움 |
| **다른 비율로 대체**(영업이익률, 이자비용/자산 등) | 분모 문제가 다른 곳으로 옮겨가지만 ICR 분자 반전 문제는 피할 수 있다 | D6에서 다룸 |

### 2. (가)를 택한 근거

| # | 근거 | 확인 수준 |
|---|---|---|
| 1 | **임의 선택값이 없다.** (나)는 분위수, (다)는 상수가 헤드라인 사양에 들어가는데, 이미 변환별 계수를 본 상태라 "그 값을 결과 보고 정했나"라는 질문에 답하기 어렵다 | 논리(에이전트 제안). 결과를 본 뒤라는 사실은 아래 3항에 기록 |
| 2 | **해석이 가장 단순하다.** β = "노출도 한 단위 높은 업종의 ICR 변화 차이(%p)". asinh 계수는 %변화로 읽지 않는 것이 맞다 | Chen·Roth(초록 확인). 단 음수가 있는 자료는 이 논문 범위 밖 |
| 3 | **극단값이 이 결과를 좌우하는 증거가 약하다.** winsorize로 잘리는 관측은 6개(하단 3: 컴퓨터 2019, 통신기기 2023, 조선 2021 / 상단 3: 담배 2020·2021·2022), β는 53.7 → 61.2(+14%) 이동. 업종 하나씩 제외 시 β 28.2~65.8, 부호 반전 0회 | **직접 확인**(이번 세션에 계산·노트북 출력 대조) |
| 4 | **업종 집계에서 극단값은 입력 오류라고 보기 어렵다.** 담배의 ICR이 2018~2023년 내내 4,600~13,500로 높고, 단기차입/자산도 0.2~5%로 낮다(2020 1.8%, 2021 0.6%, 2022 0.2%). 단, 이 높은 ICR이 영업이익이 커서인지 이자가 작아서인지는 분해하지 않았다 | 데이터 직접 확인(ICR, 단기차입/자산). 원인 분해는 미실시 |
| 5 | **두꺼운 꼬리(잔차 첨도 20.8)는 변환보다 추론 방법의 문제로 다룬다.** 어떤 변환도 첨도를 없애지 못한다(winsorize 23.0, asinh 12.0). 정식 wild cluster bootstrap(14번)으로 p값을 보고한다 | 첨도·변환 후 값 직접 확인. bootstrap은 **계획 단계**이고 정식 실행 전. 10번 6-8의 시연 p=0.190→0.225는 참고용 |
| 6 | **ICR 변환에 대한 표준 관행을 확인하지 못했다.** 확인한 문헌은 모두 0 이상 변수(Chen·Roth, Cohn·Liu·Wardlaw) 또는 변환 없이 ICR 임계값·분위 회귀를 쓰는 사례(연준 노트)이고, 음수가 있는 ICR의 변환을 권하는 직접 근거는 없었다. 그래서 "관행"이 아니라 근거 1~5로 정당화한다 | 아래 3절 |

### 3. 선행연구 확인 수준과 우리에게 주는 시사점

확인 수준: **본문**(이번 세션에 본문 열람), **웹페이지**(요약 도구 경유), **초록**(검색 결과 수준). 초록 수준 문헌은 본문 확인 전에 논문·발표에 인용하지 않는다.

| 문헌 | 확인한 것 | 우리에게 주는 시사점 |
|---|---|---|
| Chen & Roth, QJE 2024 ([arXiv 2212.06080](https://arxiv.org/abs/2212.06080)) — **본문 일부** | 초록과 2절(각주 5·9). 초록: log-like 변환 효과는 "should not be interpreted as approximating percentage effects". Y가 0 이상인 경우만 다루고 음수는 각주 5에서 제외. 0 덩어리가 없을 때도 단위 의존은 남지만 "임의적이지는 않을 수 있다"고 각주 9에서 말함 | asinh 계수를 %효과로 읽지 않는 근거. **우리 ICR에는 직접 적용되지 않음**(0 덩어리 없음, 음수 있음) |
| Cohn·Liu·Wardlaw, JFE 2022 ([저자 PDF](https://faculty.mccombs.utexas.edu/jonathan.cohn/papers/Count_data%202022aug10.pdf)) — **본문 일부** | 초록·서론. log(1+y) 회귀는 해석이 불분명하고 부호가 기대값에서 틀릴 수 있다고 하며 고정효과 Poisson을 권함. 대상은 count형·0 이상 변수 | log1p·asinh를 습관적으로 쓰는 것이 위험하다는 근거. ICR에는 Poisson을 쓸 수 없음 |
| 연준 FEDS Note 2020-12-03 ([링크](https://www.federalreserve.gov/econres/notes/feds-notes/interest-coverage-ratios-assessing-vulnerabilities-in-nonfinancial-corporate-credit-20201203.html)) — **웹페이지** | ICR을 변환 없이 다룸. ICR 1 미만 비중과 부문별 기준선, 분위 회귀, 이자비용·레버리지 하한 필터를 사용. 본문에 winsorize·로그·asinh 언급 없음. 음수 EBIT 기업이 25%를 넘는다는 서술이 있음 | ICR 자체를 다룬 선례이며 변환 없이 처리한다는 점이 (가)와 방향이 같다. 단 **기업 단위** 자료라서 우리 업종 집계와 직접 비교는 어려움 |
| Adams 외, Financial Management 2019 ([Wiley](https://onlinelibrary.wiley.com/doi/10.1111/fima.12269)) — **초록** | 회귀에서 다변량 극단값을 식별하고 그 영향을 줄이는 추정량을 제안하며, 4편의 기존 논문을 재현해 극단값 조정이 결과를 크게 바꿀 수 있다고 함. (winsorize·trim이 이 문제를 해결하지 못한다는 취지는 검색 요약에만 있고 본문 미확인) | 로버스트 추정(R4)을 강건성에 넣을 때 인용 후보. **본문 확인 전에는 인용하지 않음** |
| Mullahy & Norton, OBES 2024 / Bellemare & Wichman, OBES 2020 — **초록** | Mullahy·Norton: 0이 섞인 비음수 skew 변수에서 로그·asinh 변환은 0과 양수를 분리해 해석이 어려워지고, 변환 없는 회귀·두 단계 모형·Poisson을 권함. Bellemare·Wichman: asinh는 로그에 가깝게 쓰이지만 임의 변환에 따른 탄력성 차이가 클 수 있음 | 인용 전 본문 확인 필요. 이번 설계에서는 참고만 |
| Ippolito 외(2018) — **이전 세션에서 본문 확인한 기록**(공부노트 24-1) | 이자보상 지표 종속변수, 기업 고정효과, 양쪽 1% winsorize | 기업 단위 자료라서 업종 집계인 우리 자료에서 winsorize 근거를 그대로 가져오기 어려움 |

**종합**: ICR(음수 있음)에 특정 변환을 권하는 직접 근거는 찾지 못했다. 그래서 (가)의 정당화는 "관행"이 아니라 근거 1~5(임의 선택값 없음, 해석 단순, 극단값 영향의 측정, 업종 집계의 특성, 추론 보정)에 둔다.

### 4. 팀 의견 검토 (사실 주장을 직접 대조함)

| 주장 | 확인 결과 |
|---|---|
| leave-one-out β +28.2~+65.8, 부호 반전 없음 | **맞음** (10번 6-7). 다만 크기는 −48%(반도체 제외 28.2)까지 움직이므로 "작다"가 아니라 "부호가 안 바뀐다"로 써야 함 |
| 윈저화로 β 53.7 → 61.2 (14%) | **맞음** (61.24/53.66 = +14.1%) |

| "담배 ICR이 수만" | 분석 패널(긴축기 240행) **최대 13,480**. 전체 1994~2025 자료의 최댓값(104,014)과 혼동했을 수 있음 |
| 담배는 빚이 거의 없다 | **단기차입/자산 0.2~5%로 낮음(맞음).** 장기차입과 ICR 분해는 미확인 |
| 첨도는 점추정이 아닌 추론의 문제 | **부분적으로 맞음.** 계수의 불편성은 정규성을 요구하지 않음. 다만 오차 SD 최대/최소 ≈ 43배(10번 6-4)라 효율성 손실도 있고, 극단값은 점추정 분산도 키움 |
| "wild cluster bootstrap이 이미 설계에 있음" | **계획에는 있으나 정식 실행 전**(14번). 이 도구는 추론을 보정할 뿐 점추정의 극단값 영향을 줄이지는 않음 |
| LOO가 극단값 위험이 작음을 보여줌 | **과대 해석.** LOO가 크게 움직이는 업종은 반도체(−25.5)·통신기기(−23.2)이고, ICR 극단값 업종인 담배(+12.1)가 아님. LOO는 "특정 업종 영향"을 보이는 것이지 "ICR 극단값 영향"을 직접 재는 것이 아님 |
| Ippolito는 기업 단위, 우리는 업종 집계 | **맞음**(노트 556행: 기업 FE). 표본 크기 "수천"은 이번에 확인하지 않음 |

### 5. (가)의 약점 (로그에 같이 적음)
- 반도체·통신기기 제외 시 β가 거의 반으로 줄어듦(28.2, 30.5). 반도체 계열의 영향이 크며 D3에서 다룸.
- 잔차 이분산(오차 SD 최대/최소 ≈ 43배)과 두꺼운 꼬리(첨도 20.8)로 일반 SE·t검정의 신뢰도가 낮음 → 군집 SE + wild bootstrap 보고.
- 음수 ICR 16/240행의 분자 반전 문제는 변환으로 해결되지 않음 → D6.
- 담배 3년 연속 상단 값이 β를 낮추는 방향(담배 제외 시 65.8, p=0.10)으로 작용.
